SCOPETRACE · ONE-PAGE ARCHITECTURE
TOOL-LEVEL GOVERNANCE FOR AUTONOMOUS AGENTS

AI safety must move from prompt rules to runtime action control.

As agent autonomy increases, the safety unit is no longer the answer. It is whether each tool call is aligned with the current intent, authority, context, and egress boundary.
North Star
Agent가 현재 환경의 의도와 aligned된 방향으로만 tool을 사용할 수 있어야 한다.
Problem
Agent→ Tool→ Action
  • 잘못된 / 의도되지 않은 방향으로 tool이 사용됨
  • Context pollution이 발생하고 safety boundary가 무너짐
  • Enterprise에서는 한 번의 miss가 큰 blast radius로 확장됨
Why Existing Guardrails Are Not Enough
  • System prompt는 행동 경로를 추적하지 못함
  • Tool description은 권한·출처·수신자 맥락을 알지 못함
  • Tool-level autonomy가 커질수록 runtime decision layer가 필요함

Hard Gate

반드시 지켜져야 하는 deterministic rule. 외부 입력이 privileged retrieval, CRM mutation, memory write, sensitive egress를 유도하면 즉시 차단.

Semantic Decision

명확히 금지되지는 않았지만 맥락 판단이 필요한 경우. Evidence Packet과 precedent를 기반으로 review 또는 policy proposal 생성.
