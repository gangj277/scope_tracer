# ScopeTrace — Deck Style Lock

- **Mode**: `nano-banana-art`
- **Approved anchor**: Slide 1
- **Style summary**: Premium dark enterprise safety command-center slides with precise system diagrams, high-contrast typography, and semantic red/cyan/amber trace language.

## Background System
- **Base brightness**: dark, presentation-native canvas; graphite black around `#06090D` to `#0B0F14`.
- **Temperature**: neutral-cool graphite with warm off-white text.
- **Internal background only**: yes; every visible pixel belongs to the slide canvas.
- **Texture**: very low grain, faint technical grid, subtle trace lines.

## Palette Lock
- **Background**: deep graphite black.
- **Ink text**: warm off-white.
- **Accent**: signal red for risk, violation, cracks, blocked transitions.
- **Secondary**: electric cyan for legitimate system flow, trusted trace, protected boundary.
- **Tertiary**: muted amber for external/untrusted input and emerging agent actions.
- **Semantic usage**: never use red for neutral emphasis; never use cyan for attack paths; never introduce purple, green, or rainbow gradients.

## Texture Lock
- **Grain strength**: very low.
- **Grid / rules**: restrained, thin, technical.
- **Gradient behavior**: subtle localized glow only; no large decorative gradient backgrounds.

## Illustration / Diagram Lock
- **Style**: clean geometric system maps, thin linework, restrained icons.
- **Stroke weight feel**: medium-light, precise, neon-edge but not cyberpunk.
- **Fill behavior**: mostly transparent dark panels with cyan or amber outlines.
- **Icon language**: technical, minimal, enterprise software/security.

## Container Language
- **Card corners**: modest rounded corners.
- **Borders**: hairline cyan/amber/red based on semantic role.
- **Shadow**: internal glow only; no external object shadows.

## Accent Usage Rules
- **Red appears in**: violations, breaches, unsafe transitions, warning callouts, blocked flows.
- **Cyan appears in**: safe system path, control plane, agent boundary, trace capture.
- **Amber appears in**: external input, future autonomy nodes, untrusted source.

## Allowed Variation
- Slide layouts may vary: radial map, attack path, layered architecture, before/after split.
- Density may vary by slide objective.
- Diagrams may shift from perimeter map to flow map to lifecycle loop.

## Prohibited Drift
- No brighter or warmer editorial paper background.
- No glossy 3D objects, AI brains, humanoid robots, or sci-fi spectacle.
- No extra colors outside red/cyan/amber/off-white.
- No photoreal environments, desk/wall/room context, paper edges, framed poster, or print mockup framing.
- No tiny unreadable labels; prioritize presentation-distance legibility.
