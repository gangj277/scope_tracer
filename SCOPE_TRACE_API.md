# ScopeTrace API Endpoints

## Hard Gate Architect

### `GET /api/scope/hard-gates`

Returns hard gate rules for an agent profile.

Query:

- `agentProfileId`, default `agent_profile_support_vulnerable`

### `POST /api/scope/hard-gates`

Runs the Hard Gate Architect Agent. If `spec` is omitted, the demo support agent profile is used.

Body:

```json
{
  "agentProfileId": "agent_profile_support_vulnerable",
  "policyVersion": "v1",
  "persist": true,
  "spec": {
    "agentProfileId": "agent_profile_support_vulnerable",
    "agentName": "Nimbus AX Support Agent",
    "agentRole": "support_agent",
    "workflows": ["customer_support_reply"],
    "actorRoles": ["support_agent"],
    "recipients": ["external_customer"],
    "tools": [
      {
        "name": "search_crm",
        "category": "read",
        "riskLevel": "medium",
        "sideEffect": false,
        "externalEgress": false
      }
    ],
    "dataSources": [
      {
        "sourceTable": "crm_accounts",
        "sourceTrust": "internal",
        "dataClass": "customer_confidential",
        "authorityScope": "sales",
        "egressPolicy": "internal_only"
      }
    ],
    "safeAlternatives": {
      "privileged_retrieval": "search_public_kb"
    }
  }
}
```

Response:

- `proposal.rules`: proposed hard gate rules, all `status = proposed`
- `proposal.reviewPacket`: human-readable review summary
- `proposal.semanticRoutingMap`: default category routing by tool
- `ids`: stored rule IDs when `persist = true`

### `PATCH /api/scope/hard-gates/[ruleId]`

Updates a hard gate rule status.

Body:

```json
{ "status": "approved" }
```

Only `approved` rules are eligible for runtime hard gate lookup.

## EvidencePack Evaluator

### `GET /api/scope/evidence-packs`

Returns stored EvidencePacks.

Query:

- `agentProfileId`, default `agent_profile_support_vulnerable`
- `category`, optional
- `status`, optional: `candidate | approved | rejected`
- `limit`, default `50`

EvidencePacks are generated by red-team attacker conversations through the EvidencePack Evaluator Agent and stored as reusable decision precedents.

### `PATCH /api/scope/evidence-packs/[packId]`

Approves or rejects an EvidencePack precedent.

Body:

```json
{ "status": "approved" }
```

Only `approved` EvidencePacks are injected into semantic runtime decisions.

## Runtime Scope Decision

### `POST /api/scope/decision`

Runs ScopeTrace decision logic for a proposed tool call without executing the tool.

Body:

```json
{
  "caseId": "rt_001_pricing_leak",
  "mode": "enforce",
  "toolName": "search_crm",
  "args": {
    "customer_id": "cust_acme",
    "query": "renewal pricing"
  },
  "previousToolNames": [],
  "targetSources": [],
  "forceLlm": true
}
```

Decision flow:

```text
approved hard gate
-> category router
-> approved EvidencePack precedent injection
-> semantic allow/block decision
```

If the call is blocked, the response includes the rejection reason that the agent should receive as tool feedback.
